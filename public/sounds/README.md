# Showroom sound recordings

The showroom synthesizes its garage ambience, assembly/disassembly effects, and V12 engine start in the browser. Real recordings are optional: place files with these names in this folder and the audio engine will use them instead of the synthesized versions.

The Ferrari startup and wind recordings supplied with this project are used for the engine-start and exploded-view effects. The engine transitions to the synthesized V12 idle after the startup recording ends.

| File | Sound |
| --- | --- |
| `ambient.mp3` | Looping workshop ambience |
| `wings_of_freedom-ferrari-sound-430458.mp3` | Engine start and rev |
| `engine-idle.mp3` | Engine idle loop after startup |
| `assemble.mp3` | Component seating |
| `disassemble.mp3` | Component removal |
| `ncprime-winds-sound-effects-304060.mp3` | Wind sweep for exploded-view transition |
| `lights-on.mp3` | Headlight relay click |

Only use recordings that you have the right to use, and include any attribution required by their license.
